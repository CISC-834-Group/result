# Firefox JIT results

This folder contains the datasets and RQ1–RQ3 results for the Firefox experiments, along with the supplied Mozilla baseline. The experiments cover 15 models.

| Dataset | Period | Changes | Bug-inducing changes |
|---|---|---:|---:|
| Mozilla baseline | Supplied replication data | 98,275 | 5,149 |
| Human proxy | Nov 30, 2021 – Nov 29, 2022 | 28,459 | 3,184 |
| AI candidates | Nov 1, 2025 – Oct 10, 2026 | 9,603 | 845 |

## Where to start

For the report, start with `REPORT_NOTES.md`. The results are in:

- `results_summary.csv` — RQ1 and RQ2 metrics for each model, with sample counts and warnings.
- `rq3_coefficients.csv` — RQ3 logistic-regression coefficients, odds ratios and EALR coefficients.
- `METHOD.md` — how the data was collected, labeled and used in the experiments.

The AI dataset contains commits identified by keyword matching, author propagation and message-style scores. We refer to these commits as **AI candidates** because their authorship has not been verified. The same rules flag 12.7% of a 2019–2020 comparison dataset. The human dataset uses the 2021–2022 window as a proxy for human development. Differences between the datasets do not establish an effect of AI use.

Some product models, especially AI Toolkit and DevTools, have few bug-inducing changes and produce convergence warnings. These results should be treated as exploratory; the warnings are included in the results table.

## Data and code

`dataset_human.csv` and `dataset_ai.csv` contain the features and labels on their original scales. The normalized model inputs are in `jit/input/`, and the model list is in `model_manifest.csv`.

The data-processing scripts are in `pipeline/`, and the R experiment scripts are in `jit/script_r/`. The SZZ evidence, Bugzilla snapshot, verification records and logs are included for checking the results. Details of exclusions and code corrections are in `METHOD.md`.

## Running the experiments

The supplied run used R 4.6.1 and MASS 7.3-65. With R and MASS installed, run this from the folder:

```sh
Rscript jit/script_r/run_all.R
```

The script reuses completed stages when the inputs have not changed. To rerun everything, move `jit/output/run_status.csv` and `jit/output/results_long.csv` elsewhere first. Use the normalized files in `jit/input/` for modeling, rather than the original-scale dataset CSVs.

Use this entry point for the Firefox experiments. The `ReadMe.txt` files inside `jit/` describe the original replication package and its older entry points.

The runner writes detailed results and factor outputs to `jit/output/`. The root-level `results_summary.csv` and `rq3_coefficients.csv` summarize the supplied run and are not automatically regenerated by the runner.

The included datasets and model inputs are sufficient to rerun the models. Rebuilding the datasets from repository history also requires the original `firefox.sqlite`, a Firefox Git repository with the required history, and access to Bugzilla. Those source stores are not included in this folder.
